# Review AR integrity
Trace invoice to payment to deposit using stable identifiers and stated fallbacks. Distinguish outstanding, partially paid, closed-with-balance, unapplied, and missing-payment cases. Reconcile totals before reporting exceptions. Return affected invoices, balance exposure, missing links, and evidence freshness. Never infer that a closed status guarantees payment. A finance professional resolves each exception.
