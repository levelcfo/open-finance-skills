# Generate CFO charts
Use reconciled tables with explicit units, dates, scopes, and sources. Select the chart form that makes the operating relationship easiest to understand. Label actual, budget, forecast, and scenario data distinctly. Preserve missing periods rather than drawing zeros. Return accessible titles, annotations, source notes, and the table behind every chart. A finance professional approves the narrative.
