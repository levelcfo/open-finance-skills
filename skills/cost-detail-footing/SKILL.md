# Foot cost detail
Sum the declared detail population, compare it with the independent control total, and apply only the stated rounding tolerance. Return row count, detail total, control total, variance, and pass-or-review status. Never coerce missing rows or totals to zero. A reviewer traces every material difference before relying on the schedule.
