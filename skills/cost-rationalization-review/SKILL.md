# Review cost rationalization
Compare recurring vendors, trend, utilization evidence, contract terms, redundancy, and operating dependency. Exclude headcount by default. Separate confirmed waste from candidates requiring owner review. Return annualized opportunity, confidence, implementation risk, contract constraints, and responsible owner. Human leadership approves every change.
