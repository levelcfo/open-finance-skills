# Review customer margin attribution
Test whether revenue, labor, materials, subcontractors, and shared costs map consistently to customers and periods. Calculate margin only for supported populations. Return covered revenue, unattributed costs, confidence, and data work required. Do not publish false precision when attribution is incomplete. Human finance judgment defines allocation policy.
