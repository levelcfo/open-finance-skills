# Reconcile an account
Require a stated period, account, ledger population, and independent control source. Preserve missing values as unknown. Match exact references first, then bounded date and amount tolerances. Return matched items, unmatched populations, measured variance, and evidence freshness. Never call an account reconciled without beginning balance, ending balance, activity, and line-level coverage. A finance professional resolves every exception and signs the conclusion.
