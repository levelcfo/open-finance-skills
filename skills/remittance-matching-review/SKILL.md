# Match remittance advice
Extract stated payer, amount, date, invoice references, and communication source. Match exact references first, then bounded candidates. Return matched, partial, ambiguous, and unmatched populations with evidence links. Never apply a payment or send a message. Human review resolves ambiguity and authorizes posting.
