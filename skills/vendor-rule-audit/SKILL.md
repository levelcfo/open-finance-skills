# Audit vendor rules
Compare each rule with actual historical outcomes, exceptions, account scope, and vendor ambiguity. Return coverage, conflict rate, proposed narrow rule changes, and examples that must remain manual. Do not edit accounting rules or books. A finance professional approves any staged change.
